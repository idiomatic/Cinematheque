Usage: cinematheque [--home DIR] NOUN VERB [ARGUMENTS]
       cinematheque [--home DIR] crawl | sync | serve | refresh

The peer keeps its identity and its copy of the catalog in its home:
~/Library/Application Support/Cinematheque on macOS, and
$XDG_DATA_HOME/cinematheque (~/.local/share/cinematheque) on Linux,
unless --home or $CINEMATHEQUE_HOME names another directory.

NOUN -h (or NOUN alone) shows only that noun's commands.

USER is a user's key, as user show and member list print them; TITLE and
ITEM are title and item keys, as title list and title show print them;
REPO is a repo's ID or URL; DEVICE, a device's key, as device list
prints it.

  user show                    print this user's key
  user pair                    on a new device, show a code (and the port
                               it listens on), and wait for another of the
                               user's devices to pair this one with it
  user pair CODE [URL]         pair the new device showing CODE (found
                               nearby, or at URL), sending it this user's
                               secret and the library's founder

  library show                 print the library's ID, founder, member
                               count, and digest
  library create               create a library, founded by this user
  library join                 on a new device, show a code (and the port
                               it listens on), and wait for a member's
                               device to let this user join with it
                               (member pair)
  library leave                forget the library and this device's
                               identity, as a device removed from it must,
                               to pair again as a new device
  library handover USER [--leave]
                               hand the library over to a member

  member list                  list members
  member pair CODE [URL]       admit the user of the new device showing
                               CODE (found nearby, or at URL), sending it
                               the library's founder
  member remove USER           remove a member

  device list                  list this user's devices, by name
  device remove DEVICE         remove one of this user's other devices:
                               what it writes from now on is refused, and
                               it's told so when it next syncs

  repo list                    list repos
  repo show REPO               show a repo
  repo add URL [--rendition NAME] [--skip PREFIX]
                               add a repo: the rendition of its files,
                               if known, and the prefix of names to skip
                               (default ",")
  repo set REPO [--rendition NAME] [--skip PREFIX]
                               change a repo's settings; crawl to apply
  repo forget REPO DIR         forget a directory the repo shows as absent
                               (one that held files and lists none, as an
                               unplugged drive's mount point does), as if
                               it were deleted: its copies go, for every
                               peer (they do on their own after a year)
  repo remove REPO             remove a repo and the copies it held, for
                               every peer

  title list [TEXT]            list titles, or those whose names hold
                               the text (shortcut: ls)
  title show TITLE             show a title: its aliases, episodes or
                               versions, and where each rendition is
                               (shortcut: show)
  title download TITLE [--rendition NAME] [--to DIR]
                               fetch a title's files, or a season's
                               (TITLE/e/s01) or an ITEM's, into a directory
                               (the current one), under their repo paths,
                               from whichever copy answers first; in the
                               rendition given, else the one most items
                               have; resuming a download cut short
  title review                 list close matches and duplicates
  title facets                 count titles by facet

  alias list                   list titles that are aliases of others
  alias add TITLE TARGET       record the title as an alias of the target
  alias remove TITLE           stop a title being an alias of another

  playhead list [TITLE]        list this user's playheads
  playhead set ITEM POSITION DURATION
                               record how far this user has played, in
                               seconds
  playhead set ITEM --watched | --unwatched
                               mark an item watched, or not
  playhead remove ITEM         forget this user's playhead in an item

  peer list                    list peers found on the network, and added
  peer add URL                 add a peer that can't be found, such as one
                               off the network, on this device only
  peer remove URL              remove an added peer

  agent show [--port PORT]     on macOS, show the launch agents that serve
                               always, and refresh hourly
  agent add [--port PORT]      install and start them
  agent remove                 stop and remove them

  crawl [REPO] [--workers WORKERS]
                               crawl every repo, or one, and update
                               holdings, with concurrent workers (16)
  sync [URL]                   pull from a peer, or from every peer found
                               or added
  serve [--port PORT] [--media DIR]
                               answer peers' syncs, and serve media, on
                               the port given, else on 8008 or, if that's
                               taken, any free port
  refresh                      sync, then crawl
