Usage: cinematheque [--data DIR] NOUN VERB [ARGUMENTS]
       cinematheque [--data DIR] crawl | sync | serve | refresh

The app keeps this device's identity and its copy of the catalog in its
data directory: ~/Library/Application Support/Cinematheque on macOS, and
$XDG_DATA_HOME/cinematheque (~/.local/share/cinematheque) on Linux,
unless --data or $CINEMATHEQUE_DATA names another directory.

NOUN -h (or NOUN alone) shows only that noun's commands.

PERSON is a person's key, as person show and member list print them;
TITLE and ITEM are title and item keys, as title list and title show
print them; SOURCE is a source's ID or URL; DEVICE, a device's key, as
device list prints it.

  person show                  print this person's key
  person pair                  on a new device, show a code (and the port
                               it listens on), and wait for another of the
                               person's devices to pair this one with it
  person pair CODE [URL]       pair the new device showing CODE (found
                               nearby, or at URL), sending it this person's
                               secret and the library's founder; found
                               nearby, it's named as it advertised itself,
                               else (at URL) unnamed until it names itself

  library show                 print the library's ID, founder, member
                               count, and digest
  library create               create a library, founded by this person
  library join                 on a new device, show a code (and the port
                               it listens on), and wait for a member's
                               device to let this person join with it
                               (member pair)
  library leave                forget the library and this device's
                               identity, as a device removed from it must,
                               to pair again as a new device
  library handover PERSON [--leave]
                               hand the library over to a member

  member list                  list members
  member pair CODE [URL]       admit the person of the new device showing
                               CODE (found nearby, or at URL), sending it
                               the library's founder; its device is named
                               as person pair names one
  member remove PERSON         remove a member

  device list                  list this person's devices, by name; then
                               devices found nearby, and addresses added
  device add URL               add the address of a device that can't be
                               found nearby, such as one off the network,
                               on this device only
  device forget URL            forget an address added
  device remove DEVICE         remove one of this person's other devices:
                               what it writes from now on is refused, and
                               it's told so when it next syncs

  source list                  list sources
  source show SOURCE           show a source
  source add URL [--quality NAME] [--skip PREFIX]
                               add a source: the quality of its files,
                               if known, and the prefix of names to skip
                               (default ",")
  source set SOURCE [--quality NAME] [--skip PREFIX]
                               change a source's settings; crawl to apply
  source remove SOURCE --unavailable DIR
                               remove the copies in a directory the source
                               shows as unavailable (one that held files
                               and lists none, as an unplugged drive's
                               mount point does), as if it were deleted,
                               for every device (they go on their own after
                               a year)
  source remove SOURCE         remove a source and the copies it held, for
                               every device

  title list [TEXT]            list titles, or those whose names hold
                               the text (shortcut: ls)
  title show TITLE             show a title: its aliases, episodes or
                               versions, and where each quality is
                               (shortcut: show)
  title download TITLE [--quality NAME] [--to DIR]
                               fetch a title's files, or a season's
                               (TITLE/e/s01) or an ITEM's, into a directory
                               (the current one), under their source paths,
                               from whichever copy answers first; in the
                               quality given, else the one most items
                               have; resuming a download cut short
  title review                 list close matches and duplicates
  title facets                 count titles by facet

  alias list                   list titles that are aliases of others
  alias add TITLE TARGET       record the title as an alias of the target
  alias remove TITLE           stop a title being an alias of another

  progress list [TITLE]        list this person's progress
  progress set ITEM POSITION DURATION
                               record how far this person has played, in
                               seconds
  progress set ITEM --watched | --unwatched
                               mark an item watched, or not
  progress remove ITEM         forget this person's progress in an item

  agent show [--port PORT]     on macOS, show the launch agents that serve
                               always, and refresh hourly
  agent add [--port PORT]      install and start them
  agent remove                 stop and remove them

  crawl [SOURCE] [--workers WORKERS]
                               crawl every source, or one, and update
                               copies, with concurrent workers (16)
  sync [URL]                   pull from a device, or from every device
                               found or added
  serve [--port PORT] [--media DIR] [--web]
                               answer other devices' syncs, and serve
                               media (at /media/), on the port given, else
                               on 8008 or, if that's taken, any free port;
                               with --web, a web client at the root, which
                               browses and plays as this person
  refresh                      sync, then crawl
